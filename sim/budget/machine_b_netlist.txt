MACHINE B -- reference 4-op machine (FLIP, NEXT, PREV, SKIPZ)
Same rule and same *** REVISION NOTE *** as machine_a_netlist.txt: the
first pass's single-capacitor design had the identical race/feedback
bug, fixed here with the same master-slave storage cell (storage.py).

STATE VARIABLE: S (slave) stores flag directly; M (master) holds
flagbar_next between phases. Both capacitor-backed, never shorted
together (see machine_a_netlist.txt's charge-sharing note).

PRIMARY INPUTS (free): b1,b1bar,b0,b0bar (opcode, dual rail; encoding
FLIP=00 NEXT=01 PREV=10 SKIPZ=11); r (single rail, no complement
offered); phi1, phi2.

COMPONENTS (20 total: 13 transistors, 5 resistors, 2 capacitors, 0
diodes)

  EVAL NETWORK (always live, both phases):
    T1 (T_S, PMOS)  gate=S      a=K          b=GND         -- flag=0
    T2  gate=b1bar  a=TOGGLE_N  b=N_tog1     T3  gate=b0bar  a=N_tog1  b=K
    T4  gate=b1bar  a=MOVE_P_N  b=N_mp1      T5  gate=b0     a=N_mp1   b=K
    T6  gate=b1     a=MOVE_M_N  b=N_mm1      T7  gate=b0bar  a=N_mm1   b=K
    T8  gate=b1     a=DNODE     b=N_d1       T9  gate=b0     a=N_d1    b=N_d2
    T10 (PMOS) gate=r  a=N_d2   b=K                          -- r==0
    R1 TOGGLE_N->VDD  R2 MOVE_P_N->VDD  R3 MOVE_M_N->VDD  R4 DNODE->VDD

    TOGGLE_N = NAND(flagbar, is_FLIP)      -> toggle = NOT(TOGGLE_N)
    MOVE_P_N = NAND(flagbar, is_NEXT)      -> move+  = NOT(MOVE_P_N)
    MOVE_M_N = NAND(flagbar, is_PREV)      -> move-  = NOT(MOVE_M_N)
    DNODE    = NAND(flagbar, is_SKIPZ, r==0) -> flagbar_next, fed to the
                                                 storage cell (never
                                                 written straight into S)

  STORAGE CELL (identical to Machine A, storage.py):
    T11 (T_wm)  gate=phi1  a=DNODE     b=M
    T12 (T_buf) gate=M     a=BUF_NODE  b=GND      R5 BUF_NODE->VDD
    T13 (T_ws)  gate=phi2  a=BUF_NODE  b=S
    C1 (C_M), C2 (C_S)

TIMING: identical structure to Machine A (see its netlist's diagram):
phi1 settles TOGGLE_N/MOVE_P_N/MOVE_M_N/DNODE from the OLD (stable) S
and this tick's r; T11 captures DNODE into M. phi2: T11 opens (isolating
M from the still-live, now S-changing eval network -- no feedback,
exactly as in Machine A), T12 reads M and drives BUF_NODE=NOT(M), T13
writes BUF_NODE into S. r is read once, during phi1, before the
memory's own toggle for this tick (captured/applied at the phi1/phi2
boundary and after) -- "sample r before the toggle" holds by
construction, same as Machine A.

SKIPZ still needs r==0, tested by the PMOS T10 gated directly by r --
no separate inverter, no extra resistor, at zero cost beyond the
transistor already needed at that position in the chain.

WHERE THE 20 COMPONENTS GO
  latch (2 capacitors + isolation/buffer): C1, C2, T11, T12, T13 = 5
  shared read switch: T1/T_S = 1
  decode/strobe switches: T2..T9 (8) + T10, the r==0 PMOS (1) = 9
  pull-ups: R1..R5 = 5
  inverters: T12 (the M/S buffer; no other inverter needed -- SKIPZ's
             r==0 test is folded into T10 at no extra cost)

TOTAL: 20 components (13 transistors, 5 resistors, 2 capacitors, 0
diodes).
